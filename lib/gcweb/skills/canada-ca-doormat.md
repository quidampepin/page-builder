# Canada.ca Doormat Writer (reference)

A **doormat** is a short linked heading plus a brief description on a topic page. Acts like a highway sign — just enough to choose the right path.

## Format

**Link title**
Description text

- Title is bold, description is regular
- One blank line between doormats

## Link title rules
- 45 chars optimal; 75 max
- Front-load most important keyword
- No trailing punctuation
- No formulaic intros ("Apply for…", "Learn about…")
- Plain language — user words, not government words

## Description rules
- 120 chars optimal
- Keywords or short phrases separated by commas — not full sentences
- Don't start with "Includes…", "Information on…", "Learn more about…"
- No links, no promotion, no extra formatting
- Add new keywords not in the title

## Good example

**Express Entry**
Skilled workers, eligibility, how to apply

**Child and family benefits**
Tax credits, eligibility, application deadlines

## Bad examples
- "Immigrate to Canada Through Express Entry Program" → too long, redundant
- "Learn About Child and Family Benefits" / "Learn about the benefits available…" → wasted intro, description restates title
